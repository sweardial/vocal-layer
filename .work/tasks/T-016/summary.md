## Fix round 2
- **HIGH (partial early accept):** an early ACCEPT now also requires every 1 s window of audio that arrived after the early check (plus one window anchored at the turn end, so short tails are seen; remainder >= 0.3 s) to identify as the owner; any disagreement = REJECT, never overridden by a whole-turn match. Early REJECT stays final. Cost: a few extra embeddings at TurnEnd for long turns (hits compute latency only on early-accept path).
- **MEDIUM (unbounded queue):** `max_pending` (default 4) bounds the worker queue; excess turns are dropped with error `overflow` without blocking frames; `send_turn` has `send_timeout_s` (default 5 s, error `send_timeout`).
- **MEDIUM (silent failures):** every failed/dropped turn appends a REJECT `TurnRecord` with a fixed `error` code (`identify_error`, `send_error`, `send_timeout`, `overflow`); no exception payloads/audio logged.
- **Smoke additions:** owner + 0.5 s / full non-owner suffix without pause is rejected; flaky provider (first send fails, later commit); stalled provider with max_pending=1 gives send_timeout + overflow, all turns accounted for. Offline smoke passes `max_pending=1000` since a file source outruns real time.
- **Verified:** `make check` green (14 smokes); e2e still 8/8 owner, 0 non-owner, latency p50≈384 ms / p95≈392 ms.
- **Caveat:** window checks on real embedders may false-reject owner turns with short/noisy windows; re-measure with wespeaker on live/bench audio (follow-up if needed).

## Fix round 3
- **HIGH (short continuation):** after an early ACCEPT, audio past the early check that is longer than tail silence (0.15 s) but too short to embed alone (< 0.3 s) is treated as an unverifiable speaker change and the turn is dropped (REJECT). Smoke: 1.024 s owner + 0.16 s non-owner.
- **HIGH (fallback path):** the UNDECIDED / no-early path now applies the same continuity checks before accepting (all 1 s windows plus end-anchored window must be the owner, and speech beyond the first 1 s must be either <=0.15 s or >=0.3 s). Smoke covers it with the policy's default wide buffers (early accept impossible at the smoke threshold) for 0.16 s and 0.5 s non-owner suffixes.
- **MEDIUM (identification bound):** identification runs on one dedicated thread; submissions are capped (`max_inflight_identify`, error `identify_busy`), time-limited (`identify_timeout_s`, error `identify_timeout`), early identification is not submitted when the queue is already full, queued work is cancelled at shutdown. Early-check failure now falls back to the full-turn path. Smoke: slow matcher with max_pending=1 ends, accounts for every turn, peak in-flight <= 2.
- **Verified:** `make check` green; smoke repeated 3x stable; e2e 8/8 owner, 0 non-owner, latency p50~385 ms / p95~390 ms.
- **Known limits:** a short non-owner burst (< ~0.3 s) inside a long owner turn is invisible to window embeddings (only the end-anchored window overlaps it); owner turns whose speech runs 0.15–0.3 s past the first second are conservatively dropped. Re-measure FRR with wespeaker on bench audio.

## Fix round 4
- **HIGH (EOF speech counted as silence):** `TurnEnd` now carries `tail_samples` (trailing non-speech in `audio`). The post-early-check remainder is measured as speech only (`len - tail_samples - early_len`), with a one-frame slack; any more speech than that must be >= 0.3 s and pass the window continuity check, else REJECT. Smoke: 1.024 s owner + 0.064/0.096/0.128 s non-owner at EOF (no trailing silence), plus the earlier 0.16/0.5 s cases, with narrow and default policy buffers.
- **MEDIUM (hung matcher):** `Pipeline(matcher_factory=...)` runs identification in a spawned child process (own matcher, built by a picklable module-level factory) that is killed on timeout/cancel/close and respawned on demand; no thread outlives the run. Without a factory the thread path remains (a hung backend cannot be killed there; its backlog is capped by `max_inflight_identify`). New `scripts/smoke/smoke_identify_isolation.py`: normal turns commit via the child; a matcher that sleeps forever gives `identify_timeout`, child killed, run and interpreter exit promptly (~9 s total script time).
